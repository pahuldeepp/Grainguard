# ADR-0001: one platform, explicit compatibility profiles

Status: proposed implementation baseline, 2026-09-21.

The user wants one fresh GreenGuard combining every technology and architectural pattern from GrainGuard- and CarePulse. A historical dependency version is not a request to install several incompatible versions in one process. Different providers can fulfill the same architectural role.

Build one agricultural domain with shared contracts. Make required alternate search/cache/mesh/profiling and legacy/clinical integration exercises named profiles with acceptance tests. Preserve exact historical versions in the archive; select compatible locked versions during foundation work. Clinical reference data remains synthetic and outside agricultural scoring.

Consequences: all requested families remain accountable; the core request path stays understandable; full completion requires executing every profile, not merely adding files. Terraform and CDK have disjoint resource ownership. Outbox, inbox, saga and tenant-isolation correctness are mandatory in every applicable profile.
